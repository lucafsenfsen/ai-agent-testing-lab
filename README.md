# AI Agent Testing Lab

Independent experiments exploring how reliably AI models complete real-world software development tasks.

## Research Question

How reliably can AI coding assistants build, debug, and improve working applications?

## First Experiment: AI Coding Battle

We will evaluate AI coding assistants using identical programming tasks.

### Evaluation Criteria

- **Correctness (40%)** — Does the application work and pass its tests?
- **Instruction Following (25%)** — Were the requested features implemented?
- **Reliability (20%)** — Does the application handle errors and unexpected inputs?
- **Code Quality (15%)** — Is the code readable and maintainable?

### Initial Challenges

1. Build a responsive to-do application.
2. Debug a broken calculator.
3. Create a browser-based memory game.
4. Build a simple dashboard from sample data.
5. Improve an existing application without breaking its features.

## Research Method

We will use identical task descriptions and testing conditions wherever possible, record model versions and dates, and preserve the generated code and test results.

Results will distinguish measured performance from subjective judgments. We will report limitations and avoid claiming conclusions beyond the evidence.
